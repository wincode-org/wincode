$ wincode --help
Build, sign and upload Flutter iOS apps from Windows.

Usage: wincode <command> [arguments]

Global options:
-h, --help             Print this usage information.
    --config=<file>    The app's settings: bundle ID, team ID, profile, entitlements, CI workflow, output folder. No secrets.
                       (defaults to "wincode.yaml")
    --json             Print one JSON object on stdout when the command ends, and the messages on stderr.
    --redact           Hide the bundle ID and team ID in everything printed. Always on when the CI variable is set.
    --verbose          Also print each step, external command and HTTP request, with secrets redacted.
    --dry-run          Send, write and run nothing, and print what would be done.

Available commands:
  build       Build the unsigned IPA on the app's macOS runner (GitHub Actions) and download it.
  doctor      Check a Mach-O binary against the SDK or a reference build.
  init        Write wincode.yaml for the Flutter project in this folder.
  preflight   Check the signed IPA and App Store Connect before an upload. Read-only.
  sign        Sign the IPA for the App Store with zsign.
  status      Show the state of the app's latest uploads in App Store Connect. Read-only.
  upload      Upload the signed IPA to App Store Connect and wait for its processing.

Run "wincode help <command>" for more information about a command.
Global options go before or after the command.

Exit codes:
  0   done
  1   failed: a check found a problem, an input is wrong, or Apple or GitHub refused the work
  64  usage error, or not implemented yet
  69  a tool, the SDK or the network is missing
  70  a bug in winCode
  77  Apple or GitHub refused the credentials
  78  wincode.yaml or an environment variable is wrong

$ wincode help doctor
Check a Mach-O binary against the SDK or a reference build.

Give --binary and at least one of --sdk and --reference.

Usage: wincode doctor [arguments]
-h, --help                         Print this usage information.
    --binary=<Mach-O file>         The binary to check, such as Payload/Runner.app/Runner.
    --sdk=<iPhoneOS.sdk folder>    Check the binary against the SDK's text stubs. Fails on a library or binding that its minimum OS lacks.
    --reference=<Mach-O file>      List how the binary differs from a reference build, such as an Xcode-built copy. This does not fail.

Run "wincode help" to see global options.
